# Contributing to Voice Khata

## Getting Started

1. Fork the repository and clone your fork.
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Follow the phased roadmap in README.md.
4. Run tests before submitting: `cd backend && pytest tests/ -v`

## Code Style

- Python: follow PEP 8. Use type hints. Format with `black`.
- JavaScript/React: use ESLint + Prettier. Functional components only.
- Commit messages: use conventional commits (feat:, fix:, docs:, chore:, test:).

## Pull Request Process

1. Ensure all tests pass.
2. Update documentation if needed.
3. Request review from at least one maintainer.

## Phase Discipline

This project is built in phases. Do not skip ahead or implement later-phase features in an earlier PR. See README.md roadmap.

## Reporting Issues

Open a GitHub issue with reproduction steps and environment details.
